# Desinstalación

Si deseas desinstalar el parche, sigue este flujo.

<Steps>
### Cierra Fate/Grand Order

Antes de desinstalar, asegurate de que el juego este totalmente cerrado.

### Abre Rayshift Translate

Entra a la app y presiona el boton **Desinstalar**.

### Reabre Fate/Grand Order

Inicia el juego para comprobar que todo quedo en estado base.

### Limpia cache si es necesario

Si notas comportamiento raro, limpia cache desde el juego y vuelve a abrir.
</Steps>
