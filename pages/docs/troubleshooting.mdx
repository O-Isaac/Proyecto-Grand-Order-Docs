Si estás recibiendo un error prolongado, es posible que tu conexión a internet no sea estable. Intenta cambiar entre Wi-Fi y datos móviles (4G) o prueba nuevamente desde una ubicación diferente.

### "An internal error has occurred"

Prueba este flujo para resolver el problema:

<Steps>
### Cambia de red

Alterna entre Wi-Fi y datos moviles (4G/5G).

### Reinicia el telefono

Un reinicio limpio suele resolver bloqueos temporales de permisos o cache.

### Ejecuta Android 11 Setup

Entra en **Acerca de -> Configurar Android 11 Setup**.

### Reinstala translatefgo

Si el error persiste, reinstala la app.

### Reporta el problema

Si nada funciona, envialo desde **Reportar Error** con el mayor detalle posible.
</Steps>

#### MIUI (Xiaomi, POCO)

<Steps>
### Activa depuracion USB de seguridad

Habilita **Depuracion USB (Opciones de seguridad)** en **Opciones de desarrollador**.

### Verifica depuracion USB normal

Confirma que tambien este activa la depuracion USB normal (son opciones separadas).
</Steps>

#### ColorOS (OPPO & OnePlus)

<Steps>
### Desactiva monitoreo de permisos

En **Opciones de desarrollador**, desactiva **Monitoreo de permisos**.
</Steps>

#### Flyme (Meizu)

<Steps>
### Desactiva proteccion de pagos Flyme

En **Opciones de desarrollador**, desactiva **Proteccion de pagos Flyme**.
</Steps>
