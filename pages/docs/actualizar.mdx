# Actualizar
La aplicacion recibira actualizaciones periodicas. Mientras mantenga la app instalada, verifiquela regularmente.

## Pasos para actualizar

<Steps>
### Actualiza Fate/Grand Order

Asegurate de tener Fate/Grand Order en su version mas reciente.

### Verifica descargas pendientes

Abre Fate/Grand Order para confirmar que no haya datos pendientes, luego cierra el juego.

### Aplica la actualizacion en Rayshift

En Rayshift Translate, presiona **Actualizar** en el servidor que usas.

### Reabre el juego

Inicia Fate/Grand Order nuevamente y valida que la traduccion cargue correctamente.
</Steps>
